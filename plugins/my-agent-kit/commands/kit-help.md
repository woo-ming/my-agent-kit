description: Show the workflows bundled with My Agent Kit and how to invoke them.
---

Explain these bundled capabilities in the user's language:

- `/my-agent-kit:repo-overview`: inspect repository structure and setup.
- `/my-agent-kit:review-changes`: review a requested diff or current changes.
- `my-agent-kit:code-reviewer`: Claude Code review subagent, available through the agent interface.

For Codex, the common workflows are the `repo-overview` and `review-changes` skills, selectable through the skill picker. This help command and the Claude subagent are Claude-specific.
